# Сайт-портфолио визажиста

Лаконичный и адаптивный сайт-портфолио для визажиста. 

## 🛠 Технологии
* **HTML5** (семантическая верстка)
* **CSS3** (Flexbox, CSS variables, адаптивный дизайн)
* **JavaScript** (интерактивные элементы, мобильное меню)

## ✨ Особенности
* Полностью адаптивная верстка (десктоп и мобильные устройства).
* Шапка с быстрым переходом к контактам и иконками соцсетей (Telegram, VK).
* Секции с услугами, прайсом, информацией о макияже и обучении.

## 🚀 Запуск
Просто откройте файл `index.html` в любом современном браузере.
